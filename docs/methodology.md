# Algorithmic Methodology & Architectural Design

This document details the mathematical, algorithmic, and engineering principles behind each phase of the Nosh Robotics Computer Vision Pipeline: Foundation Segmentation (Task 1), Classical Segmentation (Task 2), Comparative Overlap Metrics (Task 3), and Multi-Object Kalman Tracking (Task 4).

---

## 1. Task 1: Pretrained Foundation Segmentation (Zero-Shot Pseudo-GT)

### Motivation & Paradigm
Training a supervised segmentation model requires dense pixel-level ground truth. With only 110 raw images containing unannotated eggs, a dual-foundation pipeline was architected to generate zero-shot pseudo-ground-truth masks:
$$\text{Image } I \xrightarrow{\text{Open-Vocabulary Detection}} \text{Bounding Boxes } \mathcal{B} \xrightarrow{\text{Promptable Segmentation}} \text{Binary Masks } \mathcal{M}$$

### Component 1: Grounding DINO Tiny (Open-Vocabulary Detection)
- **Model Architecture:** Swin-Tiny backbone with text-visual cross-attention transformers.
- **Text Prompt:** `"egg."`
- **Mechanism:** The visual features from the image and token embeddings from the text prompt are projected into a shared multimodal latent space. Cross-attention layers compute cross-modal affinity matrices:
  $$A_{i,j} = \frac{(Q_{\text{visual}} W_Q) (K_{\text{text}} W_K)^T}{\sqrt{d_k}}$$
- **Confidence Thresholds:**
  - Box Threshold: $0.25$
  - Text Threshold: $0.20$
- **Bounding Box Output:** Coordinates $(x_{\min}, y_{\min}, x_{\max}, y_{\max})$ with detection scores $s \ge 0.25$.

### Component 2: Segment Anything Model 2.1 (SAM 2.1 Tiny)
- **Model Architecture:** Hierarchical Hiera image encoder with a lightweight prompt-conditioned mask decoder.
- **Prompt Conditioning:** The bounding boxes generated by Grounding DINO are supplied as positive spatial box prompts:
  $$\text{Box Prompt } B = [x_1, y_1, x_2, y_2]$$
- **Mask Decoding:** The two-way cross-attention transformer decodes the image embedding conditioned on the box prompt embeddings, producing multi-scale mask logits.
- **Logit Binarization:**
  $$M(x, y) = \begin{cases} 1 & \text{if } \sigma(\text{logit}(x, y)) \ge 0.5 \\ 0 & \text{otherwise} \end{cases}$$
- **Post-Processing & Mask Fusion:** Multiple detected egg masks in a single scene are unioned into a consolidated multi-instance binary mask:
  $$\mathcal{M}_{\text{composite}} = \bigvee_{i=1}^N M_i$$

## 2. Task 2: Classical Computer Vision Segmentation (Algorithm E1)

### Algorithmic Rationale
Classical segmentation avoids GPU inference and neural weights, operating entirely on deterministic photometric and morphological operators. Under varying domestic lighting and complex kitchen counter backgrounds, RGB thresholding fails due to illuminance-chrominance coupling. Algorithm E1 decouples illuminance and color saturation using dual perceptual color spaces: CIE-LAB and HSV.

```
       Input RGB Image I (H, W, 3)
              |
      +-------+-------+
      |               |
      v               v
  CIE-LAB          HSV Space
      |               |
  Channel L       Channel S
      |               |
L >= P65(L)       S <= 100
      |               |
      +-------+-------+
              |
              v
       Bitwise AND Intersection
              |
              v
   Morphological Opening (7x7 Ellipse)
              |
              v
   Morphological Closing (7x7 Ellipse)
              |
              v
   Connected Component Analysis
   (Keep Area >= 500 px, Solidity >= 0.70)
              |
              v
        Binary Mask M_classical
```

### Mathematical Pipeline

#### 1. Perceptual Color Space Conversion
- **CIE-LAB:** Decouples perceptual lightness ($L \in [0, 255]$) from opposing color axes ($a^*, b^*$).
- **HSV:** Decouples chromatic hue ($H$), saturation purity ($S \in [0, 255]$), and value brightness ($V$).

#### 2. Adaptive Dual-Thresholding
1. **Lightness Threshold (Adaptive Percentile):** Eggshells (both white and light brown) exhibit higher local luminance than shadows and textured dark backgrounds. The 65th percentile of the $L$ channel is computed dynamically per scene:
   $$T_L = \text{Percentile}(L, 65)$$
   $$M_L(x, y) = \mathbb{I}(L(x, y) \ge T_L)$$
2. **Saturation Upper-Bound:** Eggshells are desaturated compared to vibrant vegetables, packaging, or painted surfaces:
   $$M_S(x, y) = \mathbb{I}(S(x, y) \le 100)$$
3. **Photometric Intersection:**
   $$M_{\text{raw}}(x, y) = M_L(x, y) \wedge M_S(x, y)$$

#### 3. Morphological Regularization
To suppress salt-and-pepper noise and bridge minor boundary discontinuities, elliptical structuring elements $K_{7 \times 7}$ are applied:
1. **Morphological Opening (Erosion followed by Dilation):** Eliminates small background specks and thin spurious filaments:
   $$M_{\text{open}} = (M_{\text{raw}} \ominus K) \oplus K$$
2. **Morphological Closing (Dilation followed by Erosion):** Bridges internal dark fissures and smooths egg perimeter:
   $$M_{\text{clean}} = (M_{\text{open}} \oplus K) \ominus K$$

#### 4. Connected Component Geometry Filtering
Connected components are extracted via 8-connectivity. Each component $C_k$ is filtered based on geometric priors of intact eggs:
- **Minimum Area:** $\text{Area}(C_k) \ge 500 \text{ pixels}$ (suppresses specular table highlights).
- **Solidity:** $\frac{\text{Area}(C_k)}{\text{ConvexHullArea}(C_k)} \ge 0.70$ (suppresses highly irregular background clutter).

## 3. Task 3: Quantitative Overlap Metrics

### Metric Formulations
Given classical prediction mask $P \in \{0, 1\}^{H \times W}$ and pseudo-GT mask $G \in \{0, 1\}^{H \times W}$:

1. **Intersection over Union (Jaccard Index):**
   $$\text{IoU}(P, G) = \frac{|P \cap G|}{|P \cup G|} = \frac{\sum_{x, y} P(x, y) \cdot G(x, y)}{\sum_{x, y} P(x, y) + \sum_{x, y} G(x, y) - \sum_{x, y} P(x, y) \cdot G(x, y)}$$
2. **Dice Similarity Coefficient (F1 Score):**
   $$\text{Dice}(P, G) = \frac{2 |P \cap G|}{|P| + |G|} = \frac{2 \times \text{IoU}}{1 + \text{IoU}}$$
3. **Pixel Precision:**
   $$\text{Precision} = \frac{|P \cap G|}{|P|} = \frac{TP}{TP + FP}$$
4. **Pixel Recall:**
   $$\text{Recall} = \frac{|P \cap G|}{|G|} = \frac{TP}{TP + FN}$$

### Metric Verification
On the held-out 22-image evaluation set, Algorithm E1 achieved:
- **Mean IoU:** $0.3506 \pm 0.1634$
- **Median IoU:** $0.3401$
- **Mean Dice:** $0.4936$
- **Mean Recall:** $0.8223$
- **Mean Precision:** $0.3822$

The high recall ($0.8223$) confirms that the photometric thresholds consistently encompass the true egg bodies, while precision reflects background over-segmentation on bright countertops.

## 4. Task 4: Multi-Object Video Tracking (SORT Architecture)

### Tracking Pipeline Architecture
Tracking-by-detection paradigm operating on 60-second video footage (1,441 frames @ 24 FPS):

```
 Video Frame F_t
        |
        v
 Grounding DINO Tiny (Box Prompt: "egg.")
        |
   Detections D_t = { (x1, y1, x2, y2, score) }
        |
        +-------------------------+
        |                         |
        v                         v
 Kalman Filter Predict      Compute IoU Cost Matrix
 x_pred = F * x_{t-1}       C_{i,j} = 1 - IoU(D_i, T_j)
        |                         |
        +------------+------------+
                     |
                     v
             Hungarian Algorithm
             (Linear Sum Assignment)
                     |
     +---------------+---------------+
     |               |               |
     v               v               v
  Matched        Unmatched       Unmatched
   Pairs        Detections        Tracks
     |               |               |
  Kalman          Spawn           Age Track
  Update        New Track         (Delete if
(z = D_match)    (ID = k++)       age > max_age)
```

### 1. State Representation & Motion Model
Each track $T$ maintains an 8-dimensional state vector in continuous 2D Cartesian space:
$$\mathbf{x} = [u, v, s, r, \dot{u}, \dot{v}, \dot{s}, \dot{r}]^T$$
Where:
- $u, v$: Bounding box center coordinates.
- $s$: Bounding box scale (area $w \times h$).
- $r$: Aspect ratio ($w / h$, assumed constant over short intervals).
- $\dot{u}, \dot{v}, \dot{s}, \dot{r}$: First-order velocity derivatives.

### 2. Time Update (Prediction)
Assuming a discrete constant-velocity motion model with sample period $\Delta t$:
$$\mathbf{x}_{t|t-1} = \mathbf{F} \mathbf{x}_{t-1|t-1}$$
$$\mathbf{P}_{t|t-1} = \mathbf{F} \mathbf{P}_{t-1|t-1} \mathbf{F}^T + \mathbf{Q}$$
Where $\mathbf{F}$ is the state transition matrix and $\mathbf{Q}$ is the process noise covariance matrix.

### 3. Data Association (Hungarian Algorithm)
- Pairwise affinity between predicted track bounding boxes $\hat{B}_j$ and detected bounding boxes $D_i$ is computed using the spatial Intersection over Union:
  $$\text{Cost}_{i,j} = 1 - \text{IoU}(D_i, \hat{B}_j)$$
- Global optimal assignment is solved via the Munkres (Hungarian) algorithm in polynomial time $\mathcal{O}(N^3)$:
  $$\min \sum_{i, j} \text{Cost}_{i,j} \cdot X_{i,j} \quad \text{s.t.} \quad \sum_j X_{i,j} \le 1, \, \sum_i X_{i,j} \le 1$$
- Associations with $\text{IoU}(D_i, \hat{B}_j) < \text{iou\_threshold} = 0.30$ are rejected as unassigned.

### 4. Measurement Update & Lifecycle Management
- **Matched Tracks:** Updated via the standard Kalman gain $\mathbf{K}$:
  $$\mathbf{y}_t = \mathbf{z}_t - \mathbf{H} \mathbf{x}_{t|t-1}$$
  $$\mathbf{S}_t = \mathbf{H} \mathbf{P}_{t|t-1} \mathbf{H}^T + \mathbf{R}$$
  $$\mathbf{K}_t = \mathbf{P}_{t|t-1} \mathbf{H}^T \mathbf{S}_t^{-1}$$
  $$\mathbf{x}_{t|t} = \mathbf{x}_{t|t-1} + \mathbf{K}_t \mathbf{y}_t$$
  $$\mathbf{P}_{t|t} = (\mathbf{I} - \mathbf{K}_t \mathbf{H}) \mathbf{P}_{t|t-1}$$
- **Unmatched Detections:** Instantiated as candidate tracks with zero initial velocities and assigned a unique incrementing Track ID.
- **Unmatched Tracks:** State projected via pure Kalman prediction without observation. If a track remains unmatched for exceeding `max_age = 20` frames, the identity is permanently terminated.
